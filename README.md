## 🚀 快速开始

添加 bucket 并安装：

```pwsh
scoop bucket add ZeroYe-scoop https://github.com/ZeroYe/scoop
scoop install ZeroYe-scoop/<软件名>
```

## ⚡ 自动更新

本仓库已配置 [Excavator](https://github.com/ScoopInstaller/Excavator)，每 4 小时自动检查更新。
